# WordPress Playground Blueprints for Kits Suite

Declarative [WordPress Playground](https://playground.wordpress.net) blueprints, generated by `build-blueprints.py`
(`npm run generate`; `npm run check` fails when files drift). Full details: `docs/release/ci-packaging-playground-release.md`.

## Version matrix
- **WordPress 7.1** (every product declares `Requires at least: 7.1`), **PHP 8.2** (the MailWeb SDK needs 8.2+; the PHP 8.0-8.3 unit matrix runs in CI).
- Networking enabled. No production credentials or secrets anywhere in the blueprints.

## Blueprints
| Blueprint | Scenario |
| :-- | :-- |
| `blueprint-base.json` | Clean WordPress with admin login, no Kits code. |
| `blueprints/directoryweb.json` | DirectoryWeb standalone (no Kits Core, no SCF); fixture listing when the listing type is registered. |
| `blueprints/rankweb.json` | RankWeb standalone, no Rank Math/Yoast; sample post. |
| `blueprints/sourceweb.json` | SourceWeb standalone. |
| `blueprints/insightweb.json` | InsightWeb standalone; asserts the dashboard answers with an honest empty state and no demo flag. |
| `blueprints/mailweb.json` | MailWeb standalone; asserts the bundled Hostinger SDK loads and no API token exists. |
| `blueprints/planweb.json` | PlanWeb standalone; sample calendar entry. |
| `blueprints/suite.json` | Optional full ecosystem: Kits theme + Kits Core + all six plugins together. |

Plugin ZIPs are fetched from the GitHub release assets of the tag in `RELEASE_TAG` (`build-blueprints.py`):
`https://github.com/wugweb-git/Kits/releases/download/<tag>/<product>.zip`.

## Running
Browser: `https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/wugweb-git/Kits/kits-suite/tools/playground/blueprints/<product>.json`
(GitHub release downloads can be blocked by CORS in a browser; use the CLI if the ZIP fails to load).

CLI against a local build (what CI does):
```bash
python3 tools/build/build-dist.py --target all
cd tools/playground && npm ci
python3 smoke.py --dist ../../dist   # swaps release URLs for the extracted ZIP contents, runs every blueprint
node validate-schema.mjs             # validates every blueprint against the official schema
```
