# Animal Writes site layer

What the distributed plugins used to carry for this one site. Not packaged (the build only reads `themes/` and `plugins/`).

Deploy this layer alongside RankWeb 2.4.0 and InsightWeb 1.2.0: those versions no longer carry what is listed here. Install: copy `rankweb/` to `wp-content/mu-plugins/animalwrites-rankweb/` and add a one-line loader `wp-content/mu-plugins/animalwrites-rankweb.php` containing `<?php require __DIR__ . '/animalwrites-rankweb/site.php';`.

- `directoryweb/site.php` and `directoryweb/includes/`: must be deployed alongside DirectoryWeb 1.4.0 (the plugin no longer carries any of it; without this layer the site loses Find help, the district helplines, local cards, Verified, Featured in, the PIN lookup, the veterinary filter and services). `includes/` holds, unchanged, what moved out of the plugin; copy the whole `directoryweb/` folder to `wp-content/mu-plugins/animalwrites-directoryweb/` and load `site.php` from `wp-content/mu-plugins/animalwrites-directoryweb.php`. site.php restores, through DirectoryWeb's filters, the 'Animals helped' and 'AWBI number' wording, the India PIN lookup and the India bounds for Near me. Copy it to `wp-content/mu-plugins/animalwrites-directoryweb.php`. Claim references now read `DW-C-` instead of `AW-C-`; existing stored references are unchanged.
- `sourceweb/config-names.php`, `directoryweb/config-names.php`, `kits-core/config-names.php`: map this site's wp-config.php constants under their earlier names (`AW_GITHUB_DISPATCH_TOKEN` to `SOURCEWEB_GITHUB_TOKEN` and `KITS_GITHUB_DISPATCH_TOKEN`, `AW_REVERIFY_DAYS` to `DIRECTORYWEB_REVERIFY_DAYS`, `AW_PHP_ERROR_LOG` to `KITS_PHP_ERROR_LOG`) to the plugins' own prefixed names; each is loaded first by its `site.php` (`kits-core-site.php`), before the plugin. `sourceweb/site.php` also supplies `sourceweb_enrich_services` from `AW_SERVICES`; the site layer defines `DIRECTORYWEB_PLACE_DETECT_SKIP`, `DIRECTORYWEB_PLACE_DETECT_CITIES`, `DIRECTORYWEB_GOV_SOURCES` and `DIRECTORYWEB_FEATURED_TYPES`, which DirectoryWeb reads.
- `insightweb/`: see its own README (links seed, visitor-counting rule, brand pattern, Rising lists).
- `rankweb/news-and-robots.php`: `/news-sitemap.xml`, its sitemap-index entry and robots.txt line, and the robots.txt Content-Signal line (RankWeb 2.4.0 dropped the two settings that switched them; this reads their saved values from `aw_seo_settings` until the Robots tab is next saved, then the defaults apply: news line on, Content-Signal off).
- `rankweb/schema-hubs.php`: section-hub and Media & PR list schema (through `rankweb_collection_page_nodes`), and the "mentions" of featured organisations on articles (`rankweb_page_schema_nodes`).
- `rankweb/listings.php`: the section hubs (`rankweb_hubs` from `AW_HUBS`), listing schema types and AWBI recognition code and description line, the Directory's "Animal" wording, the `?state=`/`?publisher=` title shapes, the FAQ index link and the country code `IN`.
- `rankweb/faq-data.php`: the FAQ module's questions and rules for listings, Library items, research summaries and tags (was `includes/faq-data.php` in RankWeb).
- `rankweb/tests/site-layer-test.php`: `php sites/animalwrites/rankweb/tests/site-layer-test.php`.
- `directoryweb/includes/registrations.php` (1.4.0): the India and animal welfare registration fields DirectoryWeb no longer carries: AWBI recognition, NGO Darpan, 12A, 80G, FCRA (stored keys unchanged), their meta schema entries, protected and team-only lists, the daily "valid until" flag, claim form rows and labels, the Registrations group on the listing page and the admin reading panel, the profile box and facts, the AWBI template-intro test, the editor group, and the filters that point DirectoryWeb at the places data. Without it the site loses those fields and the place lists.
- `directoryweb/acf-json/group_aw_listing_registrations_in.json`: the SCF field group for them (same field keys as before; the plugin's own Registrations group keeps only registration, registered as and registration date). Loaded and saved by `registrations.php`.
- `directoryweb/data/lgd.json` and `directoryweb/data/district-centroids.json`: the Local Government Directory export (states and districts, 07Oct2026) and the district centres, moved out of the plugin; `registrations.php` gives their paths to `directoryweb_places_file` and `directoryweb_district_centroids_file`.
- `directoryweb/tests/registrations-tests.php` and `directoryweb/tests/fixtures/`: check the whole schema and claim table against what DirectoryWeb 1.3.0 had. Run `php sites/animalwrites/directoryweb/tests/registrations-tests.php` (and `labels-aw-tests.php`, `site-layer-tests.php`).
- `rankweb/programmatic.php`: directory, category and tag titles and descriptions (the module RankWeb no longer has).
- `rankweb/rankweb-constant-names.php`: RankWeb's constants are `RANKWEB_*` now; this carries the earlier `AW_*` names over (wp-config overrides become `RANKWEB_*`, the saved `aw_seo_settings` keys are read under the new names, and `AW_*` is defined again for code that still reads it). Loaded first by `site.php`.
- `rankweb/defaults.php`: settings defaults (content types, hub and term titles, directory index list, brand words).
- `rankweb/site.php`: loads the two above and restores, through the plugins' filters, the contact, country, social profiles, publication name, page titles, geocoding identity, the redirect and 410 rules and the seed redirects, the site defaults (`rankweb_site_default_*`: other names, profiles, email, language, country, founding date), the Directory's scope words, the FAQ item block, the Breadcrumbs block's earlier name (`animal-writes/breadcrumb`, kept as an alias) and the `animal-writes` block namespace.

Not restored (shorter generic copy now): the media caption and description wording. The directory place description gets its scope words back through `rankweb_directory_scope`.

## Site operations list (retired 26 Nov 2026)

`docs/org/pending.md` also held the Animal Writes site's own task list: campaign pages (Diwali, community dogs, Supreme Court strays, lab rules), Home and Directory content, search and keyword fixes, social accounts, help-now and FIR state pages, owner-only server steps (`WP_MEMORY_LIMIT`, hPanel cron for `wp aw workers-tick`, Rank Math 404 log), dates and a done log. That is site content and operations, not product code; the product items from it are in each plugin's `PENDING.md`. The full text is in git history at `docs/org/pending.md`.

- `theme/site/`: the `assets/site/` folder of the Kits by Wugweb theme (templates, parts, patterns, styles, content types, campaign pages). Copied into the theme folder on the server; see `theme/README.md`.
